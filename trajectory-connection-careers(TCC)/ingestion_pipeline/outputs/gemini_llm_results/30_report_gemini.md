## 2. Risk Analysis & Feasibility Flags

* **Undergraduate Degree Status:** Graduating in 2027 means full-time employment opportunities are constrained by graduation timelines unless pursuing continued year-round internships or part-time contracts.
* **Rapid Tooling Volatility in Agentic AI:** Frameworks like LangGraph and agent orchestration standards are evolving rapidly. Relying purely on specific framework syntax rather than foundational distributed systems principles, API design, and core ML foundations poses obsolescence risks.
* **Evaluation & Determinism Challenges:** Multi-agent architectures face industry skepticism regarding nondeterminism, cascading errors, and unbounded latency. Candidates who cannot quantitatively demonstrate rigor in agent evaluation (evals, guardrails, regression testing) risk being categorized as "hobbyist wrapper" developers.
* **Balancing Breadth vs. Specialization:** Khushi’s project portfolio spans computer vision (Nrittam), embedded IoT/wearables (AirEase), distributed systems (HDFS clone), and LLM pipelines. While demonstrating versatile engineering fundamentals, hiring managers in specialized AI engineering teams look for sustained depth in data engineering and LLM system reliability.

## 3. Experience Analysis & Skills to Acquire

**Technical Skills to Acquire:**

* **LLM Evaluation & Observability:** Systematic agent evaluation tools (e.g., Ragas, DeepEval, LangSmith, Phoenix/Arize), automated benchmarking of multi-agent debate pipelines, and regression testing for non-deterministic agents.
* **Production Serving & Inference Optimization:** vLLM, TensorRT-LLM, model quantizations (AWQ/GGUF), asynchronous streaming, and self-hosted open-source model inference pipelines.
* **Advanced Graph & Symbolic Frameworks:** Semantic web standards (RDF, OWL, SPARQL), advanced Graph Neural Networks (PyTorch Geometric), and hybrid vector-graph indexing strategies (GraphRAG at scale).
* **Enterprise Security & Agent Governance:** Sandboxed execution environments (e.g., Docker/Wasm runtimes for code execution tools), role-based access control (RBAC) in agentic workflows, and prompt injection mitigation.
* **Container Orchestration for AI Pipelines:** Kubernetes deployment patterns for stateful LLM applications and microservice-driven agent pools.

**Common Transition Hurdles:**

* **Moving from Prototyping to High-Reliability Operations:** Prototype agent graphs often fail when subjected to unexpected real-world edge cases. Building resilient fallbacks, retry logic, and budget caps requires solid systems engineering discipline.
* **Managing Production Latency:** Multi-agent debate and multiple LLM hops introduce compounding latency. Engineers must learn to balance multi-agent reasoning depth with real-world response time budgets.
* **Synthesizing Hardware/Full-Stack Versatility into a Cohesive AI Narrative:** Structuring resume bullet points so that diverse experience (C/C++ firmware, OpenCV, distributed file systems) actively supports an identity as an adaptable, systems-minded AI engineer.
