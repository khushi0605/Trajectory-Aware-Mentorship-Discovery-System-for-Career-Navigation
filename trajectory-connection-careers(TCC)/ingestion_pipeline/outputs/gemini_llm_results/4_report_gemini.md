# Baseline Trajectory Report

**Background:** A motivated and ambitious database developer proficient in SQL Server, Data Modelling, BI Stack.
**Goal:** To become a senior database developer with expertise in SQL Server and BI Stack.

---

## 1. Recommended Path

* **Phase 1: Modernize Microsoft Data Platform & Modern T-SQL (Months 1–6)**
* **Objective:** Close a nearly two-decade technology obsolescence gap by upgrading legacy on-premise SQL Server skills to current enterprise standards.
* **Focus Areas:** Modern SQL Server versions (2019/2022) and Azure SQL Database; advanced T-SQL performance tuning (window functions, query store, index execution plans, in-memory OLTP, and modern partitioning schemes).
* **Milestone:** Build a robust relational data model leveraging modern SQL Server features, complete with automated backup/DR scripts, Query Store monitoring, and high-performance stored procedures.


* **Phase 2: Transition from SSIS/SSRS to Cloud-Native BI & Data Pipelines (Months 6–18)**
* **Objective:** Modernize traditional Microsoft BI stack competencies (SSIS/SSRS/SSAS) into cloud-first data solutions.
* **Focus Areas:** Azure Data Factory (ADF) / Synapse Analytics for modern ETL/ELT; Power BI (DAX, Power Query, tabular data modeling) as the modern successor to SSRS/SSAS; Azure Data Lake Storage (ADLS Gen2).
* **Milestone:** Migrate a legacy on-premise SSIS ETL pipeline and SSRS reporting suite to an Azure Data Factory pipeline feeding an optimized Azure SQL/Synapse data warehouse and dynamic Power BI dashboards.


* **Phase 3: Establish Senior-Level Data Architecture & Leadership (Months 18–30)**
* **Objective:** Re-enter the market as a true Senior Database Developer / Data Platform Engineer.
* **Focus Areas:** Cloud security and governance (Purview, row-level security, data masking), data warehouse modeling (dimensional modeling, modern medallion lakehouse concepts), and CI/CD for databases using SSDT / Flyway / GitHub Actions.
* **Milestone:** Step into a Senior Database Developer role overseeing database performance, cloud migrations, and data governance for enterprise reporting.



**Reasoning:** Although the candidate held "Senior SQL Server Developer" titles historically (2002–2007), the documented technology stack (SQL Server 2000/2005, DTS upgrades, legacy SSIS/SSRS) is completely outdated by modern industry benchmarks. To be evaluated as a modern Senior Database Developer, the candidate must quickly bridge the gap from legacy on-premise installations to modern enterprise SQL Server and the cloud-native Azure BI ecosystem.

## 2. Risk Analysis & Feasibility Flags

* **Severe Chronological Employment Gap:** The documented resume stops in August 2007, leaving a massive, unexplained employment gap. Recruiters and automated ATS filters will immediately flag this profile unless recent freelance, continuous education, or subsequent work experience is explicitly documented.
* **Obsolete Technology Stack:** The technologies listed (DTS packages, SQL Server 2000/2005, legacy SSRS) are deprecated or long past extended support. The modern SQL Server and BI market is centered on Azure Data Factory, Power BI, Databricks/Snowflake, and SQL Server 2019/2022.
* **Resume Data Quality & Presentation:** The resume contains severe OCR artifacts ("Robert Ly mith", "Infogoawikre sume, corn", "Diplorn Reale"), repeated bullet points, and copy-pasted institutional text about Providence Health. This signals poor presentation standards that will trigger immediate screening rejections.
* **Credential Disconnect:** The formal degree is listed from 1985 in music ("Bavarian State Conservatory of Music in Munich"). While non-traditional backgrounds are common in tech, having an unrelated non-technical degree paired with outdated experience increases the need for verifiable, modern vendor certifications (e.g., Microsoft DP-300 / DP-900).

## 3. Experience Analysis & Skills to Acquire

**Technical Skills to Acquire:**

* **Modern SQL Server & Azure SQL:** SQL Server 2019/2022 features, Query Store, Extended Events, columnstore indexes, dynamic data masking, and Azure SQL Managed Instance.
* **Modern Cloud ETL/ELT:** Azure Data Factory, Azure Synapse pipelines, and Python scripting for automated data ingestion (replacing legacy SSIS packages).
* **Modern Business Intelligence (Power BI & Tabular Modeling):** Power BI desktop and service, DAX calculation formulas, tabular modeling (Analysis Services Tabular / Power BI semantic models) to replace multidimensional SSAS cubes and static SSRS reports.
* **Database DevOps & Automation:** Git-based database version control using SQL Server Data Tools (SSDT), Flyway, or Liquibase integrated into CI/CD deployment pipelines.

**Common Hurdles & Transition Struggles:**

* **Unlearning Procedural/Legacy Patterns:** Legacy T-SQL practices often relied heavily on cursors, temp tables, and DTS tasks; modern SQL engineering demands set-based logic, window functions, and cloud ELT paradigms.
* **Overcoming the "Stale Experience" Perception:** The hardest obstacle will be convincing hiring teams that the candidate's skills are aligned with 2026 engineering expectations rather than 2005 on-premise administration.
* **Cloud Architecture Shift:** Moving from single-server hardware setups where developers controlled the operating system and disks to managed PaaS services (Azure SQL Database, Serverless pools) where I/O and resource allocation follow entirely different consumption and tuning rules.

* **Target Profiles & Job Titles:**
* **Lead Database Administrator / Azure Data Platform Architect:** A practitioner who has led enterprise migrations from legacy SQL Server (2000–2008) to modern Azure SQL or managed instances.
* **Principal BI Engineer / Power BI Architect:** A mentor who can guide the candidate on pivoting from traditional SSRS/SSAS reporting into modern enterprise tabular data modeling and semantic layer design.
* **Senior Technical Recruiter / Career Transition Specialist in Data Engineering:** An advisor who specializes in helping seasoned professionals re-enter the market, restructure resumes to de-emphasize long tenure gaps, and focus on practical project portfolios.



**Relevance:** These mentors will provide the exact architectural context needed to translate the candidate's foundational relational database logic into contemporary cloud-first frameworks. They can also offer critical guidance on how to present a modernized technical narrative that bypasses automated ATS filters.
